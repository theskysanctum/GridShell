A launcher-first Windows shell built for couch play, keyboard, and controller input.

Everything you reach for, in one place

GridShell is built around a full-screen launcher, but it also includes the file tools, downloads, and emulation workflows you need for a complete Windows setup.

Launcher grid

  • Apps, Web, and Games tabs — a fullscreen tile grid that works with a D-pad, stick, keyboard, or mouse.
  • Fast search — type once and filter the grid without hunting for menus.
  • Custom tiles — add, rename, change icons, or remove shortcuts; games can fetch cover art automatically.
  • Installed-game detection — Steam, Epic Games, and GOG libraries are scanned and surfaced as tiles.
  • Quick storefront launchers — Steam, Epic, GOG, and itch can launch directly from the grid.

Controller and shell

  • Controller-first navigation — broad support for Xbox, PlayStation, and Nintendo controllers.
  • On-screen keyboard — type anywhere in Windows with a controller alone.
  • Taskbar sidebar — window list, clock, and battery information, while reserving real desktop space.
  • Two run modes — side-by-side with Windows, or as the full shell with a watchdog fallback.

File Explorer

  • Dual-pane browsing — navigate two independent panes with mouse, keyboard, or controller.
  • File operations — copy, cut, paste, rename, delete, and new folder from the action menu.
  • Archive support — extract and compress to Zip and 7z using installed tools.
  • Disc image tools — convert CHD and extract Xbox ISOs for emulation workflows.

Download Manager

  • Paste a link or magnet — drop direct downloads or torrents into the queue immediately.
  • Real-Debrid — optional support for hoster unrestricting and magnet resolution.
  • Bundled aria2 daemon — fast multi-connection transfers for large files.
  • Browser capture — route browser downloads straight into GridShell.

Emulation

  • 190+ platform mappings — each system maps to RetroArch or the best standalone emulator.
  • RetroAchievements — sign in once and apply it across supported emulators.
  • ROM organization — scan default and custom ROM folders with per-platform organization.
  • Full-screen launching — emulators are configured to open directly into fullscreen.

Appearance and settings

  • Theme and accent — dark or light mode, curated palette, or custom color.
  • Tile size and fonts — adjust the interface to fit your display and taste.
  • Wallpaper support — image, video, HTML, or URL; use your active Windows wallpaper by default.
  • Widgets — overlay widgets on desktop wallpapers or full-screen backgrounds.

Networking and devices

  • Wi-Fi — scan, connect, and manage saved networks from the shell.
  • Bluetooth — pair and unpair devices and manage simple legacy PIN pairing.
  • Audio and display — adjust output/input devices, volume, monitor selection, resolution, and brightness.
  • Controller tuning — remap buttons, check LEDs, rumble, gyro, touchpad settings, and adaptive trigger support.

Safety and flexibility

  • Kiosk Mode — lock the shell down with a PIN for a child-friendly or public-facing PC.
  • Power menu — lock, sign out, sleep, restart, or shutdown directly from the grid.
  • Easy to undo — close the app, disable the shell, and your normal desktop comes back immediately.
  • Watchdog protection — if it is registered as the shell, it can fall back to Explorer after repeated failures.

See it in action

GridShell is designed to feel like a traditional launcher first, while still exposing full Windows functionality exactly when you need it.

Get started in a few minutes

The installer is self-contained. You don't have to install .NET first to get running.

  1. Download the installerGrab the latest GridShell-Setup from the GitHub releases page.
  2. Run itIt installs to C:\GridShell and asks for admin permissions so shell integration can work correctly.
  3. Pick up a controllerLaunch the app and use the D-pad or stick to move between tiles, then press face buttons to open things.

Two ways to run it

Start in safe mode to keep your Windows setup untouched. Switch to full shell mode only when you’re ready.

Next to Windows Safe

Run GridShell.exe. It hides the real taskbar while it is active, and restores Explorer immediately when you close it or choose “Restore Explorer.”

As your Windows shell Careful

Replace explorer.exe at login. A watchdog relaunches GridShell if it crashes and falls back to Explorer after repeated failures. Use this in a VM or secondary account first.

Questions

Is GridShell free?

Yes. GridShell’s own code is MIT licensed and the source is on GitHub. It also bundles a few external tools under their own licenses.

Will it break my Windows install?

Not in the default mode. It runs alongside Windows, hides the taskbar while it is active, and restores the desktop when you close it.

How do I get back to normal Windows?

Either close GridShell from the power menu or choose “Restore Explorer.” If you enabled shell mode, turn it off and your normal desktop returns at the next login.

Do I need a controller?

No. GridShell works with a keyboard and mouse too, but it is designed around controller-first navigation.

Do I need Real-Debrid?

No. Direct downloads still work without it. Real-Debrid adds support for magnet-based torrents and some hoster unrestricting.

Does it include games or emulators?

No bundled games. It maps platforms to RetroArch or a best-available standalone emulator and helps organize and launch them.

How do I uninstall it?

Use Windows Settings → Apps → Installed apps, choose GridShell, and uninstall it. If you used shell mode, disable that setting first.

Where do I report bugs or feature requests?

Open an issue on the GitHub repository.

Build it yourself

You need the .NET 10 SDK and Windows 10 (version 19041 or newer) or Windows 11.

dotnet build GridShell.slnx

Each project builds into its own bin folder. GridShell.exe is the taskbar process and starts GridShell.Grid.exe when needed.
