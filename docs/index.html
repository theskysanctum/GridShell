Everything you reach for, in one place

Every screen works with a controller first, and still works fine with a keyboard and mouse.

Launcher grid

  • Apps, Web, and Games tabs - a fullscreen tile grid you move through with the D-pad or stick, the keyboard, or the mouse.
  • Search - just start typing to filter tiles, no button to find first.
  • Tile management - add, rename, change the icon, or remove a tile; Games tiles can fetch IGDB cover art.
  • Installed games - Steam, Epic, and GOG Galaxy libraries are detected automatically and get a tile each.
  • Quick-launch storefronts - Steam, Epic, GOG, and itch sit next to the power button on every tab, and close themselves once the game you launched from them exits.
  • Anything you open slides the grid away - tiles, storefronts, File Explorer, Downloads, Settings, all of it.

Controller support

  • Broad controller recognition - Xbox, PlayStation (DualShock 4 / DualSense), and Nintendo Switch Pro / Joy-Con pads, via SDL3.
  • Nintendo-aware on-screen keyboard - hint labels swap to match A/B/X/Y on a Switch-layout pad automatically.
  • Controller Manager - turns a pad GridShell can read but Windows' XInput can't into a virtual Xbox 360 controller (ViGEm), and can hide the original device (HidHide) so apps only see one.
  • Per-controller tuning - button remap, LED color (DualShock 4 / DualSense), rumble, gyro/accelerometer, touchpad click mode and sensitivity, and experimental adaptive triggers (DualSense).
  • On-screen keyboard - type anywhere in Windows with a controller alone.

File Explorer

  • Dual-pane browsing - two independently navigable panes, full controller support alongside mouse and keyboard.
  • File operations - copy, cut, paste, rename, delete, and new folder, from a popup menu reachable by right-click, a controller button, or the keyboard.
  • Archives - extract or compress to Zip and 7z, via whichever of 7-Zip or PeaZip is installed.
  • Disc images - compress to CHD and extract Xbox ISOs for emulation, right from the file list.

Download Manager

  • Paste and go - drop in a direct link or a magnet link.
  • Real-Debrid - optional; unrestricts hoster links and resolves magnets/torrents when you add an API token.
  • Fast transfers - a bundled aria2 daemon handles the actual downloading.
  • Browser capture - a small Chrome extension sends your browser's downloads straight into the Download Manager.

Emulation

  • 190+ platforms - each mapped to RetroArch or the best standalone emulator, and set to open fullscreen.
  • RetroAchievements - log in once, and it's applied automatically across every RetroArch, Dolphin, and PCSX2 you've set up.
  • ROM organization - scans a default ROMs folder plus as many extra folders as you add, each with its own per-platform subfolder.

Appearance

  • Theme and color - dark or light theme, a curated accent-color palette, or your own custom color.
  • Tile size - small, medium, or large.
  • Fonts - four bundled fonts, or point it at your own font file for the whole UI.
  • Start button icon - a curated icon gallery, or your own image.
  • Wallpaper - a local image, video, or .html file, or a live URL; defaults to your current Windows wallpaper if you leave it blank.
  • Widgets - overlay widgets on top of an image or video wallpaper.

Taskbar sidebar

  • Window list - see and switch between every open window, with a click bringing the grid down out of the way automatically.
  • Clock and battery - including battery levels for connected Bluetooth devices, not just the PC itself.
  • Behaves like a real taskbar - reserves its own strip of desktop space, and stays out of Alt+Tab itself.

Networking and devices

  • Wi-Fi - scan, connect, and manage saved networks, without relying on Windows' own networking UI.
  • Bluetooth - scan, pair, and unpair devices, including simple legacy PIN pairing.
  • Audio - pick the output/input device and set volume for each, independent of Windows' own mixer.
  • Display - switch the primary monitor, change resolution, and adjust brightness where supported.

Safety and flexibility

  • Two ways to run it - next to Windows with zero side effects, or as the full Windows shell (replacing explorer.exe) with a watchdog that falls back to Explorer if GridShell keeps failing.
  • Kiosk Mode - a PIN lock that blocks editing tiles/widgets/wallpaper and exiting GridShell, for handing the PC to a kid.
  • Power menu - lock, sign out, sleep, restart, or shut down, right from the grid.
  • Easy to undo - close it, or turn the shell setting back off, and your normal desktop is back immediately.

Get started in a few minutes

The installer includes everything it needs. You do not have to install .NET first.

  1. Download the installerGet GridShell-Setup from the latest release on GitHub.
  2. Run itIt asks for administrator permission and installs to C:\GridShell. Leave "Launch GridShell" ticked at the end.
  3. Pick up a controllerGridShell opens on the launcher grid. Use the D-pad or stick to move, and the face buttons to open things.

Two ways to run it

Start with the first. It changes nothing about how Windows starts.

Next to Windows Safe

Run GridShell.exe. It hides the real taskbar while it runs. Close it, or pick "Restore Explorer", and Windows is back right away.

As your Windows shell Careful

Replaces explorer.exe at login. A watchdog restarts GridShell if it crashes and falls back to Explorer after repeated failures. Try it in a virtual machine or a spare account first, because it changes how your whole session starts.

Questions

Is GridShell free?

Yes. GridShell's own code is MIT licensed, and the source is on GitHub. It bundles a few other tools, like aria2 and chdman, under their own licenses.

Will it break my Windows install?

Not in the default mode. GridShell runs next to Windows, hides the taskbar while it is open, and puts everything back when you close it. Only the optional "use as my Windows shell" setting changes how Windows starts.

How do I get back to normal Windows?

Running next to Windows: just close GridShell, or choose "Restore Explorer" - your normal desktop is back immediately. Running it as your Windows shell is different: closing GridShell only gets you Explorer for the current session. You have to go into GridShell's Settings and turn the "Use GridShell as the Windows shell" option back off yourself, or GridShell replaces Explorer again on your next login. The watchdog only steps in on its own if GridShell keeps crashing - it doesn't turn the setting off for you otherwise.

Which controllers work?

Xbox, PlayStation (DualShock 4 and DualSense), and Nintendo Switch Pro / Joy-Con controllers all work, through SDL3.

Do I need a controller?

No. Everything works with a keyboard and mouse too.

Do I need Real-Debrid?

No. It is optional. Without it, the Download Manager still downloads regular links with aria2. Real-Debrid adds support for magnets and hoster links.

Does it come with games or emulators?

No games. GridShell maps each platform to RetroArch or a standalone emulator and sets it up to open fullscreen, and it adds tiles for games you already have in Steam, Epic, and GOG Galaxy.

Windows says it does not recognize the installer.

That is Windows SmartScreen, which warns about files it has not seen much. You can check the source and the release on GitHub. Choose "More info", then "Run anyway", if you are comfortable.

How do I uninstall it?

Use Apps in Windows Settings, find GridShell, and choose Uninstall. Turn off the shell setting first if you used it.

Where do I report a bug or ask for a feature?

Open an issue on GitHub.

Build it yourself

You need the .NET 10 SDK and Windows 10 (version 19041 or newer) or Windows 11.

dotnet build GridShell.slnx

Each project's bin folder then holds its executable. GridShell.exe is the taskbar process, and it starts GridShell.Grid.exe for you.
