Built from https://github.com/libsdl-org/SDL at tag release-3.4.20, with SDL_HIDAPI_LIBUSB=ON (dynamic-load libusb backend), to support wired Nintendo Switch 1/2 controllers, which SDL's official prebuilt Windows binaries do not include. libusb-1.0.dll built via vcpkg (libusb 1.0.30); see libusb-1.0.LICENSE.txt (LGPL-2.1) for its license. Loaded dynamically at runtime, not statically linked.
